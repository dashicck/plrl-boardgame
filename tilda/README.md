# Подготовка карточек ПЛРЛ для Tilda — черновик

Эта ветка **не меняет** рабочий `main`. На данный момент созданы файлы:
- [Большой формат](large-zero-block.html)
- [Маленький формат](small-zero-block.html)

## Что сделано
- Товарные страницы собраны из актуальных `app.js`, `styles.css` и `gallery.css`.
- Убрано использование локальной корзины `laptaCart` и переход на `checkout.html`; вместо него добавление через штатную ссылку Tilda `#order:Название =Цена`.
- Убран браузерный механизм хранения отзывов: он создавал отзывы, видимые только одному посетителю.
- Предусмотрены два связанных товара и переходы на основную страницу.
- CSS изолирован внутри `@scope (#plrl-tilda-product)`; браузер должен поддерживать CSS `@scope`.
- **Файлы пока не тестировались в редакторе Tilda**. Наличие исходников не означает, что магазин готов.

## Перед вставкой

1. Создайте в Tilda две черновые страницы, сохраните их URL.
2. Загрузите 10 изображений из папки `assets` репозитория в файловое хранилище Tilda или на другой доступный по HTTPS публичный хостинг. Приватный GitHub **не является** публичным CDN: ссылки `raw.githubusercontent.com` для приватного репозитория посетителям не подойдут.
3. Перед каждым HTML-элементом с кодом карточки добавьте конфигурацию ниже, заменив `URL_...` реальными публичными URL:
```html
<script>
window.PLRL_TILDA_CONFIG = {
 home: "/URL-ПОСАДОЧНОЙ/",
 large: "/URL-БОЛЬШОЙ/",
 small: "/URL-МАЛЕНЬКОЙ/",
 assets: {
  "assets/large-box-front.png": "URL_LARGE_FRONT",
  "assets/large-box-spine.png": "URL_LARGE_SPINE",
  "assets/large-box-top.png": "URL_LARGE_TOP",
  "assets/large-box.webp": "URL_LARGE_BOX",
  "assets/large-set.webp": "URL_LARGE_SET",
  "assets/small-box-front-print-hd.png": "URL_SMALL_FRONT",
  "assets/small-box-side-print-hd.png": "URL_SMALL_SIDE",
  "assets/small-box-top-print.png": "URL_SMALL_TOP",
  "assets/small-box.png": "URL_SMALL_BOX",
  "assets/small-set.png": "URL_SMALL_SET"
 }
};
</script>
```
4. Добавьте блок ST100 «Корзина с формой заказа» **на обе страницы товаров** и настройте единые параметры хранения товаров; **не включайте** настройку «Не сохранять товар в корзине». Не добавляйте корзину в общий header/footer основного сайта.
5. Для фиксированной доставки в ST100 → «Контент» → «Поля ввода» → тип «Варианты доставки» укажите единственный вариант:
```
Доставка =199
```
6. Не подключайте приём реальных заявок и оплату до согласования; тестируйте в режиме предпросмотра. По документации Tilda реальные проверки оформления требуют опубликованной страницы — не публикуйте без разрешения.

## Важное ограничение
`#order:Название =Цена` — официально документированный Tilda способ добавить единичный товар в корзину. Но он **не делает HTML-карточку автоматически синхронизированной с Каталогом товаров Tilda**. Пока цены берутся из исходного `product.js`: маленький — 699 ₽; большой — 1299 ₽. Для полной синхронизации с каталогом потребуется настроить официально поддерживаемые товарные блоки с `Product ID` и привязать элементы интерфейса. Не публикуйте магазин до проверки расхождения цен/остатков.

## Что ещё требуется
- Сверить точный вид в Tilda и мобильную версию.
- Настроить ссылку «Перейти к оформлению» (в черновом коде она открывает уже установленный ST100 через штатную иконку; потребуется проверить после установки блока).
- При необходимости скрыть визуальную иконку ST100 **только на этих двух страницах**, не влияя на другие страницы сайта.
- Связать кнопки на главной странице «Копия Настольная игра Лапта».
- Подключить каталог и проверить цены/остатки.
- Позже подключить платежи и СДЭК; стоимость покупателю всё равно 199 ₽.

Официальная документация: https://help-ru.tilda.cc/online-store/cart и https://help-ru.tilda.cc/online-store/one-product
