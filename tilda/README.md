# PLRL / Tilda — draft integration, 18 November 2026

## Сохранённый результат
Корневые large.html и small.html включают режим data-commerce="tilda".
В этом режиме app.js не обращается к прототипной корзине laptaCart: цену и добавление передаёт tilda/native-cart.js.
«Перейти к оформлению» — обычная ссылка #opencart, без добавления товара.
Удалено подключение прототипной формы отзывов, сохранявшей их локально.
Дизайн, 3D-коробки, фото комплектации и тексты взяты из исходного репозитория. Работа ограничена отдельной веткой; main и опубликованный сайт не менялись.

## Реальная степень готовности
Код и HTML подготовлены. В Tilda в этом этапе ничего не сохранено: встроенный браузер не открыл проект по тайм-ауту.
Импорт Zero, адаптивы и реальная связь с ST100 НЕ проверены. Не считать ветку готовым интернет-магазином.

## Файлы для установки
- dist/large-zero.html, dist/small-zero.html: самостоятельный HTML со встроенным CSS для импорта в Zero. Обычные тексты/кнопки должны оставаться редактируемыми после импорта. Не вставлять весь файл в T123.
- dist/large-runtime-t123.html, dist/small-runtime-t123.html: интеграция штатной покупки и восстановление 3D-галереи внутри существующего Zero; ставить по одному модулю на соответствующую страницу.
- dist/*-tabs-t123.html: вкладки с клавиатурным управлением и изолированными стилями.
- native-cart.js: адаптер штатного товарного блока. Он не создаёт свою корзину, не вызывает приватные функции Tilda, не отправляет заказы.
- store-config.json: запись требуемых настроек, НЕ файл импорта Tilda и НЕ подтверждение их применения.

Оригинальные фотографии комплектации встроены в сгенерированные файлы как data URI. Поддержку импорта этих изображений проверить в Zero; при необходимости загрузить оригиналы assets/large-set.webp и assets/small-set.png в Tilda и заменить адреса. Подписанный URL инструкции PDF сохранён из исходника; доступность/срок его действия не подтверждены.

## Привязка существующих блоков
Большая страница: 393845309, Zero rec5905398501, Product ID 119874176573.
Маленькая: 393982709, Zero rec5907133401, Product ID 342470682193.
Посадочная: 390011009; резервная копия: 393839909.
Не создавать повторно эти страницы или товары. Актуальное состояние нужно сверить после восстановления доступа.

1. На странице установить штатный блок единичного товара (например ST200/ST205/ST210/ST215/ST405) и синхронизировать по существующему Product ID.
2. Назначить этому блоку CSS-класс plrl-native-large либо plrl-native-small. Он должен содержать ровно одну штатную ссылку #order:... с актуальной ценой. Адаптер читает эту ссылку после синхронизации каталога и делегирует клик штатной кнопке. Если структура другая, адаптер отключает собственную покупку — требуется проверить фактическую разметку.
3. После импорта Zero проверить сохранение/назначить CSS-классы группам:
   plrl-product-gallery — вся галерея;
   plrl-price — цена;
   plrl-add — добавление;
   plrl-minus/plrl-plus — кнопки количества;
   plrl-quantity — контейнер поля количества;
   plrl-status — статус, с текстовым .tn-atom.
   Ссылка оформления — #opencart.
4. Поле количества должно остаться настоящим input. Если импорт превратил его в фигуру, заменить небольшим HTML-элементом с input id="qty". При отсутствии единственного штатного числового поля в исходном товарном блоке количество до добавления ограничивается одной единицей; редактирование в ST100 остаётся штатным. Поддержка выбора количества до покупки в конкретном блоке требует проверки.
5. Установить соответствующий runtime. Старый gallery-boot.txt отключить в черновике, чтобы два механизма не изменяли одну галерею.
6. Добавить вкладки. Manrope/Oswald подключить для элементов карточки без замены глобальных шрифтов остальных страниц.
7. Один ST100 на каждой из трёх страниц: скрыть иконку, отключить автоматическое открытие после добавления, оставить штатное сохранение корзины. Подтверждение успешного добавления принадлежит Tilda: адаптер не показывает вымышленное «Добавлено» только на основании клика.
8. native-cart.js наблюдает изменения цены/доступности и повторно читает штатный блок перед покупкой. Если товар ещё не загружен, кнопок несколько, цена некорректна или штатная кнопка отключена, добавление блокируется.
9. Не прятать штатный исходный блок до проверки. Его окончательное оформление/расположение рядом с Zero ещё не выполнено.

## Магазин и оформление — осталось настроить/проверить в Tilda
Предварительные цены 699/1299 ₽ остаются в каталоге; фактические остатки нужно подтвердить. Доставка 199 ₽ один раз на весь непустой заказ, без бесплатного порога.
Поля: ФИО, телефон, email, город, адрес/ПВЗ; комментарий необязательный.
Не подключать реальные платежи, получателей тестовых заявок или отправку заказов СДЭК.
Не публиковать. Для будущего подключения нужны договоры/реквизиты провайдеров, реквизиты продавца и чеков, данные отправителя и реальные вес/размеры упаковки.
Юридические документы и реальные отзывы не выдумываются и этим кодом не созданы.
Ссылки посадочной #plrl-large/#plrl-small нужно заменить на /lapta-large и /lapta-small в существующих кнопках.
Страница успешной отправки и юридические ссылки ещё не настроены.

## Проверки
В корне репозитория:
node tilda/build.cjs
node tilda/test.cjs

34 проверки пройдены: ошибочные/неоднозначные источники цены, недоступный товар, изменение цены, ограничение количества, передача количества штатному полю, повторный клик, повторная инициализация, отсутствие собственного хранения корзины, синтаксис модулей, оформление без добавления.

Не выполнено: визуальное сравнение и ширины 1920/1440/1200/960/640/480/375/320; нативный импорт Zero; переходы/перезагрузка общей корзины; проверки формы, доставки и уведомлений в Tilda. Расчётные контрольные суммы: 699+199=898, 1299+199=1498, 699+1299+199=2197, 1299*2+199=2797 ₽. Это ожидаемая арифметика, не результаты тестов ST100.

https://help-ru.tilda.cc/online-store/one-product — синхронизация по Product ID и штатные ссылки #order.
